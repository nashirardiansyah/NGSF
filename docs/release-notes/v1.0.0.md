## Updating an existing install

This is the first public release, so there is nothing to update yet. For future releases, this section lists the code zip and any migration patch.

## What's included

- Config-driven pages, sections and fields
- Section types: table, matrix, dashboard, gantt, warehouse, content
- OTP email login and role-based access
- Rules, cascades, derived columns and live count/list/sum/avg tokens
- Version history, soft delete and restore
- PDF printing, email notifications, CSV/XLSX import
- In-app builder
- PatchSync (optional)
