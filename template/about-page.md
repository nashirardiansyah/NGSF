## About this app

This app is built with **NGSF**, a config-driven app framework for Google Sheets.

**Version:** 1.0.0

### Source, updates and help

- Source code and releases: https://github.com/nashirardiansyah/ngsf
- Report a problem: https://github.com/nashirardiansyah/ngsf/issues
- Security issues: email nashir.ardiansyah@gmail.com (please don't post them publicly)

To update, download the latest release and replace **all** code files in Extensions → Apps Script. Don't make a new copy of the template, or you'll start with empty data.
