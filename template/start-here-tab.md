NGSF v1.0.0 — a config-driven app framework for Google Sheets

You're looking at your own copy. Nothing here is shared with anyone until you deploy it.

TO GET STARTED
1. Open Extensions → Apps Script.
2. Click Deploy → New deployment → Web app.
3. Set "Execute as" to Me, choose who has access, and click Deploy.
4. Authorize the script. An "unverified app" warning is normal for a personal Apps Script project: choose Advanced → Go to (project name) → Allow.
5. Open the Web app URL (ends in /exec). You, the owner of this spreadsheet, are Admin automatically.

Full install guide: https://github.com/nashirardiansyah/ngsf#install-about-15-minutes

GOOD TO KNOW
• Build pages in the app's builder rather than by editing the Config_ tabs directly.
• The app runs with your Google permissions. Deploy from an account that only holds this app's files.
• Only emails in the Users tab can sign in.
